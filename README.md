# IDMDR - Interactive Data Mapping Repository and Distribution

IDMDR is an Interactive Data Mapping Repository and Distribution built with Vue 3, TypeScript, and Vite. 

## Project Setup


### Install dependencies using npm:

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
